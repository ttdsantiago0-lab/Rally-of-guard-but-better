# Rally of the Guard

Mod de NeoForge 1.21.1 que convierte a los guardias de Guard Villagers en un ejército coordinado: formaciones,
doctrinas medidas con simulación, Battle Planner y, más adelante, tributo, caravanas y facciones.

- Plan y estado: `docs/PLAN_MAESTRO.md`, `docs/AVANCE.md`, `docs/MANUAL_DE_CAMPO.md`.
- Requiere Guard Villagers 2.4.11 (no incluido; se descarga de Modrinth).
