- Veredicto: **explicado** (cuenta en la ficha, razón 2,1× frente a 2,05× medida). Camino GV: `getMobArrow(…, 1.0)` → base = 2·1,0 + triangular(dif·0,11, 0,574) ≈ 2,22; `shoot(…, 1.6F, 0)`; sin crítico. Camino Rally: `ArrowItem#createArrow` → base 2,0; `shoot(…, 3.0F, spread)` (`WeaponProfile` arco 3,0); `setCritArrow(true)` siempre. Daño 1.21 = ceil(|v|·base) y, si crítico, + nextInt(j/2+2). Con el arrastre (0,99/tick, g 0,05) a 8-30 bloques: Rally |v| 2,9-2,7 → ceil(≈5,5)=6, +crítico media 2 → **8,0**; GV |v| 1,42-1,48 → ceil(≈3,2) → **3,7** (normal; 3,5-3,9 de fácil a difícil). Medido F77: 7,6 / 3,7. Reparto: velocidad ×1,6 y crítico ×1,33. El 7,6 < 8,0 cuadra con golpes dentro de i-frames (solo cuenta el exceso). Lectura para O7: el ~2× por impacto es **arma (velocidad de lanzamiento + crítico), no coordinación**; el multiplicador de fuerza de Rally contra GV nativo incluye este factor.
